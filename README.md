# Kerung Hilfe – Website

Diese Website ist für GitHub Pages vorbereitet und benötigt keinen Build-Prozess.

## Dateien
- `index.html` – Inhalt und Seitenstruktur
- `style.css` – Gestaltung
- `script.js` – DE/EN-Umschaltung und Guide-Platzhalter
- `assets/images/` – hier später Bilder ablegen

## Auf GitHub hochladen
1. Öffne dein bestehendes Repository.
2. Klicke **Add file → Upload files**.
3. Ziehe `index.html`, `style.css`, `script.js` und den Ordner `assets` hinein.
4. Unten **Commit changes** wählen.
5. Öffne **Settings → Pages**.
6. Unter **Build and deployment / Source**: **Deploy from a branch**.
7. Branch **main**, Ordner **/(root)** wählen und **Save**.
8. GitHub zeigt nach der Veröffentlichung die Adresse der Website an.

## Inhalte ändern
Texte stehen in `index.html`. Deutsche und englische Varianten sind über `data-de` und `data-en` hinterlegt.

## Guides ergänzen
Die acht Karten werden in `script.js` erzeugt. Für eine spätere Version können vollständige Profile als eigene HTML-Abschnitte angelegt werden.

## Bilder
Bilder in `assets/images/` hochladen. Nur Bilder verwenden, für deren Veröffentlichung die erforderliche Zustimmung vorliegt.

## Videos
Für eine schlanke GitHub-Pages-Seite Videos vorzugsweise über einen Videodienst einbetten, statt große Videodateien im Repository abzulegen.

## Vor Veröffentlichung prüfen
- Namen und Status aller Betroffenen
- sachliche Beschreibung der Katastrophe
- Bankdaten
- Zustimmung zu Fotos/Videos und persönlichen Informationen
- rechtliche/steuerliche Formulierung zur privaten Hilfsinitiative und zu Spendenquittungen
